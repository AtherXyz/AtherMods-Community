# Changelog / Registro de cambios

## English

This PARTIAL tester selection packages two existing, unchanged ZIPs as individual release assets. No mod code or behavior was changed while preparing this release.

- Beefalo Saddled No Poop: 2.0.0, Android delivery r18; original liolok MIT notice retained.
- Ather Combo Counter Attack: 0.1.0-alpha6-client; exact previously tested candidate retained.
- Added bilingual installation, checksums, credits and prerelease documentation for this selection.
- The previous v0.10.1-alpha39 release remains separate and unchanged.
