# Installation and issue reports / Instalación e informes de errores

## English

1. Back up your worlds and mod settings. Use your existing Ather Mods installation; no APK is included.
2. Download the two individual ZIP assets from this release after publication. Match their filenames and SHA-256 values in [CHECKSUMS.md](CHECKSUMS.md). Keep the ZIPs unchanged.
3. Import each ZIP through the app's mod import function. Use the version shown by the imported mod, not only the ZIP filename. Do not enable duplicate versions together.
4. Enable Beefalo Saddled No Poop as a server mod for your test world. Enable Combo Counter Attack in the global client-mod selection. Start with a disposable local test world.
5. Test each mod alone before combining it with your other mods. If loading or gameplay fails, disable the affected mod and keep your backups.

For a bug report, use the repository's Issues page. Include app/game/mod versions, device model and Android version, whether the world is local or multiplayer, other enabled mods, reproduction steps, expected/actual behavior and a screenshot if useful. Remove account details, credentials, personal paths and unrelated private information before sharing diagnostics. Physical testing on one device does not guarantee other devices or mod combinations.

Expected assets: `ather-modpack--workshop-1769805475-mobile-r18.zip` and `ather-modpack--Ather-Combo-Counter-Attack-0.1.0-alpha6-client.zip`.

## Español

1. Respalda tus mundos y ajustes de mods. Usa tu instalación existente de Ather Mods; no se incluye una APK.
2. Después de la publicación, descarga los dos ZIP individuales de esta release. Contrasta nombres y SHA-256 con [CHECKSUMS.md](CHECKSUMS.md). Conserva los ZIP sin modificarlos.
3. Importa cada ZIP mediante la función de importación de mods de la aplicación. Comprueba la versión del mod importado, además del nombre del ZIP. No actives versiones duplicadas a la vez.
4. Activa Beefalo Saddled No Poop como mod de servidor del mundo de prueba. Activa Combo Counter Attack en la selección global de mods de cliente. Empieza con un mundo local desechable.
5. Prueba cada mod por separado antes de combinarlo con otros. Si falla la carga o la partida, desactiva el mod afectado y conserva tus respaldos.

Para informar de un error, usa la sección Issues del repositorio. Incluye versiones de aplicación, juego y mods; modelo y versión de Android; mundo local o multijugador; otros mods activos; pasos, resultado esperado y observado, y captura si ayuda. Elimina datos de cuenta, credenciales, rutas personales e información privada ajena al problema antes de compartir diagnósticos. Una prueba física en un dispositivo no garantiza otros dispositivos o combinaciones.

Assets previstos: `ather-modpack--workshop-1769805475-mobile-r18.zip` y `ather-modpack--Ather-Combo-Counter-Attack-0.1.0-alpha6-client.zip`.
