# Ather Modpack — Two-mod tester selection / Selección de dos mods para testers

## English

PARTIAL selection: two mods only. This is not the complete Ather Modpack and contains no application APK. Jeff Modlist is a separate catalogue; no Jeff Modlist package is included here. This is an unofficial community project, not a Klei or Playdigious release. A legally installed game is required; game files are not included.

- **Beefalo Saddled No Poop 2.0.0** by **liolok**, MIT: prevents saddled beefalo from producing manure. Server mod; enable it for the intended world.
- **Ather Combo Counter Attack 0.1.0-alpha6-client** by **Ather**: client-side combo display using your attacks and replicated health loss. Damage attribution during simultaneous multiplayer attacks is approximate. Client settings apply across worlds.

Ather reports testing the exact Combo ZIP on a physical device. No new automated gameplay or universal device-compatibility test is claimed for this selection. These are prerelease tester downloads. Back up your worlds before trying mods.

See [installation](INSTALL.md), [release notes](RELEASE-NOTES.md), [checksums](CHECKSUMS.md), [changelog](CHANGELOG.md) and [credits](THIRD-PARTY-NOTICES.md). Individual downloads will appear as release assets after publication; no new download link is asserted here.

## Español

Selección PARCIAL: solo dos mods. No es el Ather Modpack completo y no contiene la APK de la aplicación. Jeff Modlist es un catálogo independiente; no se incluye ningún paquete de Jeff Modlist. Este proyecto comunitario no es una publicación oficial de Klei ni de Playdigious. Se necesita el juego instalado legalmente; no se incluyen sus archivos.

- **Beefalo Saddled No Poop 2.0.0**, de **liolok**, MIT: evita que los beefalos ensillados produzcan estiércol. Es un mod de servidor; actívalo para el mundo correspondiente.
- **Ather Combo Counter Attack 0.1.0-alpha6-client**, de **Ather**: muestra combos en el cliente usando tus ataques y la pérdida de vida replicada. La atribución de daño cuando coinciden ataques multijugador es aproximada. Los ajustes de cliente se comparten entre mundos.

Ather comunica haber probado el ZIP exacto de Combo en un dispositivo físico. Esta selección no acredita pruebas nuevas de jugabilidad automática ni compatibilidad universal. Son descargas de prerelease para testers. Respalda tus mundos antes de probar mods.
