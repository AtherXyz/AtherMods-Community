# Ather Modpack — PARTIAL tester prerelease / Prerelease PARCIAL para testers

## English

Two individual, unchanged mods: **Beefalo Saddled No Poop 2.0.0** by **liolok** (MIT) and **Ather Combo Counter Attack 0.1.0-alpha6-client** by **Ather**. This is a PARTIAL Ather selection, not the complete modpack. No APK or other mods are included. Jeff Modlist remains independent.

Back up worlds, import the ZIPs into your existing app, verify SHA-256 and test in a disposable world. The release commit includes INSTALL.md, CHECKSUMS.md, CHANGELOG.md and THIRD-PARTY-NOTICES.md under ather-modpack/two-mods-20261030-r1/. Report reproducible bugs through repository Issues after removing private data. Each ZIP is a separate release asset. v0.10.1-alpha39 is preserved.
