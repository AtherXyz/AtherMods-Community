# Instalación / Installation

**ES:** Esta guía describe Eco82. Su APK aún no tiene descarga pública autorizada; no sustituyas otra versión ni uses la guía de alpha39 como si correspondiera a Eco82. Conserva tus partidas y los ZIP originales antes de cambiar la selección.

**EN:** This guide describes Eco82. Its APK does not yet have an authorized public download; do not substitute another version or treat the alpha39 guide as an Eco82 guide. Keep your saves and original ZIPs before changing the selection.

| Paso / Step | Español | English |
| --- | --- | --- |
| 1 | Cuando esté disponible, descarga Ather Mods desde [Descargas](DOWNLOADS.md), verifica su versión e instala la APK. Permite instalar desde esa fuente solo si Android lo solicita. | When available, download Ather Mods from [Downloads](DOWNLOADS.md), verify its version and install the APK. Allow installation from that source only if Android requests it. |
| 2 | Instala tu copia original de Don't Starve Together desde Google Play. No se proporciona el juego. | Install your original copy of Don't Starve Together from Google Play. The game is not provided. |
| 3 | El entorno probado es Playdigious Android 2.3.1, código 100. No se ha confirmado compatibilidad con versiones posteriores. | The tested environment is Playdigious Android 2.3.1, version code 100. Compatibility with later versions has not been confirmed. |
| 4 | Instala e inicia [Shizuku](https://shizuku.rikka.app/) siguiendo sus instrucciones oficiales. Debe seguir activo al usar Ather Mods. | Install and start [Shizuku](https://shizuku.rikka.app/) following its official instructions. Keep it running while using Ather Mods. |
| 5 | Abre Ather Mods y concede su solicitud de autorización de Shizuku. Usa el selector de Android para permitir acceso a los ZIP elegidos. El permiso de superposición solo es necesario si activas el atajo flotante opcional. | Open Ather Mods and grant its Shizuku authorization request. Use Android's file picker to grant access to selected ZIPs. Overlay permission is needed only for the optional floating shortcut. |
| 6 | Pulsa «+ Importar ZIPs» para uno o varios ZIP, o «Importar carpeta». La biblioteca importada no equivale a mods activados. | Tap “+ Importar ZIPs” to import one or more ZIPs, or “Importar carpeta” to import a folder. Imported library entries are not automatically enabled mods. |
| 7 | Los mods de cliente se comparten entre mundos. Los de servidor se seleccionan y configuran por mundo. | Client mods are shared across worlds. Server mods are selected and configured per world. |
| 8 | Guarda y sal de cualquier partida. Pulsa «Abrir menú de mods del juego» y confirma «Ya he guardado y salido; continuar». Esta acción no guarda la partida por ti. | Save and leave any running world. Tap “Abrir menú de mods del juego” and confirm “Ya he guardado y salido; continuar”. This action does not save the world for you. |
| 9 | En el juego abre Mods, elige los mods de cliente y guarda la selección. En la configuración de cada mundo, elige y guarda sus mods de servidor. Acepta el reinicio si el juego lo pide y arranca el mundo. Mantén Ather Mods y Shizuku activos. | In the game, open Mods, select client mods and save the selection. In each world's settings, select and save server mods. Accept a restart if requested by the game and launch the world. Keep Ather Mods and Shizuku running. |
| 10 | Si falla, anota el mensaje y los pasos. En Ather Mods usa «Exportar registro de diagnóstico» y revisa el archivo para retirar datos personales antes de compartirlo. Consulta [Testers](TESTERS.md). | If it fails, record the message and steps. In Ather Mods use “Exportar registro de diagnóstico”, then review the file and remove personal data before sharing it. See [Testers](TESTERS.md). |

**ES:** Los nombres entre comillas son los botones reales de la interfaz española. No se necesitan comandos manuales para seleccionar mods. No actives duplicados o versiones distintas del mismo mod.

**EN:** Quoted button names are the actual Spanish UI labels. No manual commands are needed to select mods. Do not enable duplicates or different versions of the same mod.
